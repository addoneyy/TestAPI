# API接口自动化测试框架
## 主要内容
>  ### 框架
> * **Python + pytest + requests + allure + Jenkins**
> ### 用例层
> * **设计单接口用例和业务流用例**
> * **采用pytest的parametrize，对于单接口用例，传入不同的参数来测试不同的用例，提升用例编写效率**
> * **结合yaml实现数据与脚本分离，从而将测试框架由脚本驱动转变为数据驱动**
> * **利用私有函数完善业务流用例**
> * **在yaml中结合sql语句实现关键case的数据库校验**
> ### 工具层
> * **采用yaml自定义标签实现token实时更新问题**
> * **对yaml中variables变量进行替换**
> * **采用反射机制，对结果校验函数进行断言**
> * **使用pytest函数收集测试结果**
> * **二次封装基础请求类requests**
> * **使用自定义的装饰器记录请求参数与响应结果**
> * **引用yagmail自动发送测试报告邮件**
> * **使用钉钉机器人自动推送测试结果**
> * **jenkins自动推送allure报告到钉钉消息**
